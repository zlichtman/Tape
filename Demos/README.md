# Tape demo material

`1.x/screenshots/` holds the README's images. Each is a screenshot of the real app:
Tape 1.33, built from this repository, running on a GitHub-hosted macOS 27 virtual
Mac at 1920 × 1080 with Activity Monitor, TextEdit, Finder, Terminal and Preview, on
the built-in Mac Blue wallpaper. Tape used its factory layout. The TextEdit note and
Terminal output are sample content.

The menu shot is cropped to the menu; nothing else was edited. The images were
converted with `cwebp -q 84 -m 6`, and every one is referenced by the README.
Videos live on the website (zlichtman.com/tape), not here.
