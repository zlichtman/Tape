# Tape demo material

`1.x/screenshots/` holds the README's images. Each is a screenshot of the real app:
Tape built from the 1.31 source, running on a GitHub-hosted macOS 26 virtual Mac at
1920 × 1080 with Safari, TextEdit, Finder, Terminal and Preview. Tape used its
defaults, plus Resize Columns Together with One Third widths so three columns fit in
view. The Safari page is zlichtman.com; the TextEdit note and Terminal output are
sample content.

The Settings image is Tape 1.32's Shortcuts page, captured the same way in Tape's
`--ui-preview` mode. The hero places the Before and With Tape captures side by side
with their titles.
The menu shot is cropped to the menu; nothing else was edited. The images were
converted with `cwebp -q 84 -m 6`, and every one is referenced by the README.
Videos live on the website (zlichtman.com/tape), not here.
