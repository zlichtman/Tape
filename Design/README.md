# Tape icon

- `tape-mark.svg`: the mark on a 100-unit grid. A solid strip with torn ends and two cut panel lines: your windows side by side on one strip.
- `tape-app-icon.png`: 1024 px app icon. The mark is white on a black rounded square, matching MacSpaces' notch moon. The website uses the same file at `/tape-app-icon.png`.

The style follows the solid geometric symbols in Yasaburo Kuwayama's *Trademarks & Symbols, Vol. 2* (1973). It is an original mark, not a copy of one from the book.
